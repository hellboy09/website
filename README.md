# Bhuvanesh A — Portfolio

A responsive personal portfolio built from the resume and ready for GitHub Pages.

## Deploy with GitHub Pages

1. Create a new GitHub repository, for example `bhuvanesh-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. GitHub will provide your public Pages URL.

No build tools or server are required.

## Customize

- Edit text in `index.html`.
- Change visual design in `styles.css`.
- Change interactions/theme behavior in `script.js`.
- The site is mobile responsive and includes a light/dark theme toggle.
